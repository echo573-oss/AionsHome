# 外部平台、好友串门与维修室

## 把对话接到哪里

| 场景 | 第一次怎样接入 |
| --- | --- |
| 在微信继续家庭聊天 | 配置 OpenClaw 微信桥接，扫码登录，把微信绑定到选定的聊天窗口。微信消息会进入该窗口，开启持续微信模式后可在微信接着聊。[微信部署教程](../../微信接入部署教程.md) |
| 让伴侣参与 QQ 群 | 打开「QQ 群聊 → 机器人接入」，给要接入的角色填写自己的 AppID 和 AppSecret，保存并连接。开启回复后在目标群 @ 对应机器人完成首次配对，两位可分别配置。 |
| 去另一个小家做客 | 和朋友交换会客室 MCP 地址与对应角色的访客 Key，在「好友串门」为那位伴侣配置好友。每次拜访有独立记录；如果想接待别人，再部署自己的会客室。[串门使用说明](../../说明&教程/AI好友串门使用说明.md) · [会客室部署](../../AionsHome-Visitor-Lounge/README.md) |

**QQ 的参与和记忆可以分开调。** 每个角色可选「仅 @ 回复」或「主动接话」，各群另有参与和记忆开关。主动接话需 QQ 允许机器人接收普通群消息。群消息和交往记忆按角色、群与成员分别保存；可选择让伴侣把重要的朋友回忆带回小家。

**家庭留言板**适合双方不同时在线的情况。可以在家里或朋友的板上留便签、看回复。配置巡看后，伴侣也会来读，看到或回复过的话题会留下经历。

微信桥接设置好之后，还可以开启「工具与能力 → 微信消息」：伴侣在小家多次联系你、一直没收到回应时，可以往已绑定的微信发一条简短提醒。

## 浏览与收藏

- **小红书巡游**可以指定目标账号和本次行动说明，选择让哪位伴侣去看看。要在平台上真实评论或回复，需另外打开对应权限；结果可在巡游日志里回看。
- **淘宝心愿角**通过淘宝的 MCP 工具搜索商品。电脑上的淘宝需要登录并开启 AI 代理；可以手动搜，也可以让伴侣按最近聊过的事选搜索词。收藏篮保存发现时的价格和逛街小记，购买时以商品页为准。[淘宝接入说明](../../docs/taobao-3-compatibility.md)
- **联网查资料**可在设置中配置 Tavily。日常聊天就能发起搜索、读取网页，结果会交回当前对话。要接自己选择的外部工具，入口在[娱乐室](games.md)的「去外面逛逛」。

**聊天里的心愿袋。** 伴侣逛淘宝后发来的「心愿袋」会显示这次带回的商品，点卡片即进入对应的逛街记录，可以看选中它们的理由。收藏只记录这次发现。

**在聊天里点瑞幸。** 在「设置 → 瑞幸咖啡 MCP」配置 Token、默认位置和门店，开启下单能力后，明确告诉伴侣想点什么。主私聊和聊天室都能显示待支付订单卡；由你核对后扫码或打开支付页确认。付款后回到原卡片点「查询取餐码」，可以看到最新状态。

## 维修室

先在服务电脑打开「维修室」，从「设备配对」取得配对码，将手机接入。每件要帮忙处理的事有独立任务，可发附件、找文件、讨论修改方案。确认方案后开始执行，结束时可验收并回传到群聊。[维修室服务入口](../repair_routes.py)

## 日常聊天读取 NAS MCP（试用）

在娱乐室「去外面逛逛」连接 MCP 服务器，点「聊天读取」，为岚和 Connor 分别勾选要开放的只读工具，再到「工具与能力」开启「日常聊天 MCP 读取」。

在岚的私聊、Connor 私聊或家庭群聊，直接向希望使用工具的角色提出明确请求，例如「帮我从 @Vault 列出根目录」。只有真实用户的最新请求中出现 `@服务器名`，且该角色已获授权，系统才会按需调用最多一个只读工具。群聊里两位角色各有独立权限；自动巡逻、环境语音和 AI 相互接话不会单独触发读取。普通闲聊不会额外连接 MCP 或加载工具目录。

工具名称只用于初步筛选，实际是否只读仍需要由你审阅工具说明；敏感数据可能会进入当前选择的云端模型。

## MCP 写入审批（施工版）

在娱乐室连接 MCP 后，点击「写入审批」，分别为岚、Connor 授权具体的非破坏性写入工具。然后在「工具与能力」手动开启「日常聊天 MCP 写入审批」（默认关闭）。

你在当前聊天明确提出写入请求，例如「帮我把这段话写进 @Vault 的 Test.md」。模型先拟定一次工具调用，**此时不会写入任何内容**。聊天页面出现审批卡，完整列出工具名与参数；你点击「确认执行」之后，后端还会再次确认角色权限和工具是否存在，才发送这一笔操作。点击「取消」则直接作废。

提案保留在本机进程内存中，5 分钟过期，确认后不能重复执行。远端超时或断线时，操作结果可能未知，请先检查目标应用，不要马上重复发送。服务器重启后，未执行提案自动失效。

当前写入候选只涵盖名字显示为 create、write、append、add、update 的有限操作，排除删除、支付、登录、发送消息、执行代码等高风险工具。这只是初筛，服务端实现是否真正安全仍需要用户审阅。每笔写入都要求你查看**具体内容与目标路径**再确认。密码和 API Key 不应通过普通笔记写入工具保存；独立加密密码库在后续施工。

审批卡会在私聊、Connor 私聊或家庭群聊的当前页面出现。群聊同一条用户请求只建立一份待确认提案，不会让两位 AI 双重写入。

## 本机表单资料与凭据库（施工版）

在 Windows 上用浏览器打开 `http://localhost:8080/form-vault`，或从「近期生活与待办」页面进入「填表资料 · 本机」。这一页暂时只接受 Windows 本机的 loopback 请求，不接受 NAS、手机、Tailscale 或远程代理访问。

- **表单资料**：可保存多套常用姓名、电话、邮箱、地址等资料，按需要编辑或删除。
- **网站凭据**：按 HTTPS 网站根域名和用户名保存账号。密码从保存开始就不会回显到网页/API；登录列表只显示名称、网站和用户名。
- **存储**：两类记录统一写到 `aion-chat/data/form_vault.dpapi`，使用 Windows 当前用户的 DPAPI 加密。该路径已被项目 `.gitignore` 中的 `aion-chat/data/**` 规则排除，不可提交到 Git。
- **未来填表调用**：内部接口需要匹配保存的记录 ID 与当前 HTTPS 网站的**精确域名**才能取得凭据；当前没有暴露获取密码的 HTTP 或 MCP 接口，也没有联通自动浏览器填写。

这套资料库完全独立于「近期生活与待办」的模型画像、Memory 与日常对话。当前不向 AI 提供地址或密码，不通过聊天指令直接管理它们。未实现的部分包括浏览器自动填表、加密凭据导入/导出、多设备同步以及银行卡管理。

**恢复注意**：DPAPI 绑定到启动 AionsHome 的 Windows 用户。仅复制加密文件到另一台电脑或换 Windows 用户，不保证能解密。换机前需要专门的迁移流程；现阶段不要把正式账号密码唯一副本放在这里。文件损坏或解密失败时会报错，不会用空数据覆盖原文件。

**安全注意**：加密静态文件防范硬盘上的直接明文泄露；已获得同一 Windows 用户权限的其他本机进程仍可能访问解密能力。新功能在最终集中验收前不要写入真实密码，先用假账号验证本机限制、跨站拒绝、系统用户一致性和 Windows DPAPI 行为。
