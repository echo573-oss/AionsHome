# 《河》章节功能

《河》是 AionsHome 的独立长篇叙事页面，入口：日记本顶部「书写 → 河」，或直接访问 /river。

## 当前可用

- 目录阅读：章节、标题、副标题、发生时间、正文，以及「后来怎样理解」。
- 新建、编辑、归档/恢复章节；每次编辑都会保存旧版本，可从「修改历史」恢复。
- 在章节里保存原文来源文本与原子记忆 ID；可以搜索现有主记忆库并选中一条作为关联。
- 直接导入《河》的窗口手稿 Markdown：页面右上角「导入」，选择 <窗口编号>-河.md。每个以「## RAW-0005-RIVER-0001｜标题」开头的段落生成一篇草稿；相同手稿编号不会重复导入。已经存在的手稿默认跳过，不覆写编辑成果。
- 章节的改写、恢复、归档**不会修改已有原子记忆**，也不会自动进入日常对话的记忆召回。

## 数据

第一次访问 API 时，在现有 AionsHome SQLite 数据库中创建 river_chapters 和 river_revisions。不单独开数据库，也不复制记忆正文。章节的关联为 memory_ids，展示时在 memories 表中只读查找；原子记忆被删除时仍保留原 ID 和「已不存在」提示。主记忆库的访问控制由站点现有中间件负责。

source_key 对应各窗口的 RAW-0005-RIVER-0001 编号，建有唯一索引；version 用于防止两个页面同时编辑产生静默覆盖。历史版本可以恢复，而当前版本会先写入历史。

原子记忆文档里的 RAW-0005-AM-0001 属于整理卡片编号，**不等于** AionsHome 的 mem_... 数据库 ID。Markdown 导入时将卡片编号保存在原文线索里；等原子记忆入库并有了实际 ID，再通过编辑器建立对应关系。

## 启动与验收

更新仓库后，重启 FastAPI 服务，打开 /diary 或 /river。先新建一篇草稿，编辑并查看历史、尝试归档/恢复，再导入一份测试 Markdown，检查是否重复导入。

后端测试：在 aion-chat 目录运行 python -m unittest test_river -v。

后续可增加来源原文的一键跳转、跨窗口主题编排、记忆修正候选与《河》双向联动；这些都尚未自动启用。
